# Agent Note: v0.2.23 ARM64 升级与生产部署

Status: implemented

## Problem

生产升级基线为自定义 v0.2.22 r1，提交 b58f403cd91c6a586d9b5234803b8a265f2d3685。用户明确要求适配并部署官方 v0.2.23。官方标签 5af9afb588c4b014b3df9db7d4073af1f8ae01b6 的 VERSION 为 0.2.22；新增 252_channel_pricing_ultrafast_multiplier.sql，渠道定价、缓存用量和流式切换行为必须兼容现有固定控制台及本地计费。

## Decision

合并固定 v0.2.23 标签并显式发布为 0.2.23，继续使用 Go 1.27.4 和 linux/arm64。保留当前固定前端基座、历史公开页、已删除社群入口状态、工单、计费定制、出站私网拨号校验和严格 CSP 缓存 generation 保护。不自动启用 Ultra Fast 或 MCP。

固定控制台会重建渠道价格对象，原始编译代码的载入和保存转换均未包含 ultrafast_multiplier，可能清除通过 API 配置的覆盖值。装配阶段仅为新增卡片、载入已有卡片、保存价格三处增加该字段透传，不增加控件、不修改固定基座字节或摘要。回归直接执行生成产物中的 mt/ut 载入保存函数，验证未设置、NULL、1、1.25、3 的往返和其他价格编辑，并验证重复装配不会叠加补丁。仅在后端把省略强制当作保留可减少前端改动，但会改变官方价格数组替换以及显式 NULL 的清除语义，因此在固定前端装配层补齐载荷。

新迁移保留官方完整文件名和字节。历史 v0.2.22 迁移测试固定到 251 号迁移范围，使 309→311 的历史断言不随新版本漂移。新增 311→312 的隔离迁移与生产副本回归，核验历史 checksum、关键表行数、渠道价格全部旧字段、分组 Fast/Ultra Fast 开关、NULL 默认值、正数约束、重复执行及旧账本兼容。失败写入约束测试只在隔离库运行，恢复副本只迁移和读取。

官方计费内存测试现在自带独立子进程隔离，并修复测试夹具的用户分组费率缓存生命周期；采用官方版本替代上一版的等效本地隔离。新版测试依赖的 model_pricing_resolver_channel_normalized_test.go 和 openai_gateway_passthrough_function_args_test.go 从同一标签完整恢复，保留测试体和断言，避免仅拷贝工具函数后丢失配套回归。

上线前创建权限 600 的 PostgreSQL custom-format 备份并实际恢复。发布绑定干净提交、不可变标签、镜像架构、版本和内容摘要，只重建 sub2api；保留 PostgreSQL、Redis、leaderboard 的容器和数据。备份、迁移、测试、部署、运行时和浏览器证据存于 deploy-artifacts/0.2.23-arm64-20261118。

## Related decisions

检索活跃笔记后，[v0.2.22 发布](../../implemented/process/2026-11-17-v0222-arm64-release.md) 与本篇部分重叠，保留其缓存失效与测试隔离依据；本篇负责新版本和新迁移，不取代旧篇。[历史公开页](../../implemented/feature/2026-10-28-restore-public-pages.md)、[删除社群入口](../../implemented/simplification/2026-11-12-remove-community-dialog.md) 和 [出站私网策略](../../implemented/bug-fix/2026-10-13-url-private-host-policy.md) 是独立保留约束。没有需要废弃的其他同主题 proposed 笔记。

## Alternatives considered

官方镜像可立即提供完整新功能，但会覆盖本地界面和后端定制，故继续源码合并构建。直接恢复官方前端可提供 Ultra Fast 定价控件，但改变用户当前控制台与公开页，故保留固定前端并核查省略字段兼容。仅部署补丁能缩小变更，却无法完整覆盖缓存用量与计费契约，故合并固定发布标签。

## Testing

Go 1.27.4 完整 unit、vet、unit+embed 的 web/server 测试通过。前端类型检查及 19 项集成/导航（含新增渠道价格往返回归）、生产构建、4 项画布测试、15 项发布回归通过。隔离 PostgreSQL 的 303→306、306→309、309→311、311→312 迁移全部通过。本次备份 173796145 字节，SHA256 为 4628bcd50093dd6658c09fb953c5da4c2fdd1a35755db2d777a570e4b12c22b2；实际恢复含 311 项迁移、604 位用户、4 张工单、494352 条用量记录。生产恢复副本上的 311→312 迁移约 0.41 秒，历史 checksum、关键数据、价格、策略、默认值与重复执行验证通过，临时副本清理。

## Consequences

本次纳入官方缓存用量统计、GPT-6.2 元数据、渠道 Ultra Fast 定价和首输出超时预算修复，同时维持现有界面。固定控制台不会自动获得官方新增管理控件。新增价格字段默认 NULL，沿用模型默认 Ultra Fast 价格；本次不改写渠道价格或分组设置。应用镜像回滚不撤销数据库迁移，备份必须保留。浏览器验收不真实提交登录、支付、OAuth 或模型请求。
