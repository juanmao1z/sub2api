# Agent Note: 删除公开首页社群弹窗

Status: implemented

## Problem

用户要求删除刚上线 v0.2.21 首页的社群弹窗。首页来自历史源码并有摘要保护，需要明确这次裁剪范围，避免为了保持原始摘要又恢复该功能。

## Decision

删除 HomeView 的社群入口、Teleport 弹窗、开关状态、Escape 监听和专用动画。保留其他首页导航、统计、主题、登录和自定义首页分支。sources.json 继续记录原始摘要，HomeView 加入明确的适配文件清单，其余 54 个历史文件继续逐字节验证。历史语言和共享图片不在本次删除范围内，首页不再引用社群文案或图片。

## Related decisions

检索活跃笔记后，[恢复公开页](../../implemented/feature/2026-10-28-restore-public-pages.md) 与本篇部分重叠，继续持有入口隔离、认证、CSP 和历史来源约束；本篇只收窄社群功能。[v0.2.21 发布](../../implemented/process/2026-11-12-v0221-arm64-release.md) 保留后端与发布约束，不被取代。

## Alternatives considered

只隐藏弹窗或删除弹窗模板可以减少改动，但会留下无效入口、状态或事件监听，因此同时删除功能入口和专用实现。删除历史语言和共享图片能进一步减少文件，但扩大历史来源偏离且不影响弹窗是否存在，因此保留未被首页引用的资源。

## Testing

验收执行前端构建、类型和既有集成检查、笔记门禁，以及桌面和 375px 首页浏览器检查；确认无社群按钮与弹窗，主题和其他导航仍可用。发布构建 linux/arm64，版本仍为 0.2.21，只切换应用并核验保留服务 ID、健康和线上资源摘要；结果保存于 deploy-artifacts 对应发布目录。

## Consequences

HomeView 不再逐字节等于历史版本，必须保留来源摘要和明确适配说明，不能重写原始 SHA256。后端和数据库迁移无变化，数据库备份沿用已经实际恢复验证的本次 v0.2.21 备份。
