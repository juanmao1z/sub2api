# Agent Note: v0.2.17 页面补全与发布兼容

Status: implemented

## Problem

当前生产前端由固定摘要的控制台资源和集成层组装。无限画布入口引用 `/canvas/`，但原资源目录没有对应应用。线上使用说明菜单的 ID 为 `cc-switch-guide`，内容地址是 `md:cc-switch-codex`，固定前端无法解释该文档标识。官方 v0.2.17 包含网关、支付和模型兼容修复，需要保留工单、计费和出站安全改动。

## Decision

合并官方 v0.2.17 提交 `060d0160417782cd962a0c7f460f6cd4565d4916`，保留定制构建和业务路径。官方 VERSION 为 0.2.16，项目显式构建为 0.2.17。后端移植全部发布差异；固定控制台通过组装层移植 Stripe 订单与本地恢复快照的 client_secret 绑定，并移除导航 URL 中的 client_secret。

说明页源码位于 `frontend/kedaya/runtime/usage-guide.js` 和对应 CSS，复用真实 AppLayout、站点主题与 origin，提供占位 API 示例、目录、复制、FAQ 和站内功能入口。`/usage-guide` 及 `/custom/cc-switch-guide` 等旧地址指向同一登录后页面；侧栏过滤已替代的两个旧菜单 ID，避免重复入口，不修改线上设置数据。

画布源码位于 `frontend/kedaya/canvas/`，保留原入口的分组和密钥生命周期。应用启动后移除 URL 查询参数；密钥仅保留内存，用于同源 `/v1/models`、`/v1/chat/completions` 和 `/v1/images/generations`，不发往外站。按用户与密钥 SHA-256 摘要隔离本地画布，导入导出限制为 100 节点、3 MB 的版本化 JSON，拒绝敏感字段和危险图片源，文本通过 textContent 渲染。账户切换清理旧视图。生成操作支持取消、真实错误和重试，不提供伪造结果。

组装层验证固定资源摘要、唯一替换锚点和自有资源摘要；发布清单覆盖说明页和画布。开发服务器支持目录 index.html 与 .mjs 类型。窄屏顶栏隐藏搜索和订阅快捷按钮，保留菜单、公告、工单、语言及用户入口。

## Related decisions

活跃笔记检索仅命中 [出站私有地址策略](../../implemented/bug-fix/2026-10-13-url-private-host-policy.md)，分类为相关但不重叠；合并保留其传输与 socket 校验及测试。本篇不替代该决定。被历史删除的官方测试和必要辅助文件从同一官方标签恢复，不使用桩替换实际逻辑。

## Alternatives considered

直接修改固定压缩资源能较快展示页面，但会破坏来源校验且难以维护，选择在组装时通过精确锚点接入独立源码。复用已有画布入口能保留分组和密钥生命周期；仅保留入口无法弥补缺失应用，因此保留入口并补全应用。恢复整套官方前端能直接接收上游 UI 修复，但会丢失用户要求保留的控制台界面，继续使用当前构建并移植必要契约。

## Testing

后端 go test ./...、go vet ./... 通过。前端集成检查覆盖旧地址别名、实际懒加载文件、产物摘要、Stripe 快照绑定和原有生产适配；画布纯函数测试覆盖同源边界、危险图片、导入结构和敏感数据。隔离浏览器检查覆盖旧菜单地址、单一导航入口、复制、示例切换、FAQ、目录、375px 暗色布局、真实画布 iframe、密钥 URL 清理、本地保存恢复、生成成功与 429 重试，运行时无错误。浏览器生成请求使用本地测试接口，不消耗生产模型额度。

## Consequences

页面可独立维护，固定资源来源仍可复核；后续基础资源升级必须重新核对 Vue 导出和唯一锚点。画布保存在本浏览器，支持 JSON 导入导出，不提供跨设备同步或视频生成。可用模型和生成结果取决于分组、余额及上游能力。仅发布四个画布运行文件，测试源码不进入静态产物。生产发布继续只重建 sub2api，核对 ARM64 镜像版本、修订、摘要和保留服务容器 ID。
