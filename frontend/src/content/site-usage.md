# 网站使用说明

本页汇总 `zhouz.online` 的计费方式、分组选择、API 地址和常见使用问题。创建 API 密钥前，请先根据调用平台、价格和稳定性要求选择分组。

> 分组、倍率、模型权限和可用渠道会随线上配置变化。本页不固定列出分组名称和倍率，请始终以[密钥管理](/keys)和模型广场中的实时信息为准。

## API 地址

当前 OpenAI 兼容 API 地址为：

```text
https://api.zhouz.online/v1
```

配置客户端时请同时填写 API 密钥和该地址。地址末尾必须保留 `/v1`；如果客户端单独要求填写组织或项目 ID，按客户端提示填写即可，不能用组织 ID 代替 API 地址。

## 计费说明

### Token 请求如何计费

文本请求会分别计算输入 Token、输出 Token、缓存读取和缓存创建等费用，再乘以密钥当前生效的倍率。

`实际费用 = 模型基础费用 × 当前生效倍率`

模型基础费用会根据实际模型、Token 类型、上下文长度和服务层级分别计算，因此不能只用总 Token 数直接估算。请求完成后，请到[使用记录](/usage)查看最终费用和明细。

### 当前生效倍率

默认使用密钥所属分组的倍率。如果账户配置了该分组的专属倍率，则专属倍率会替代默认倍率。启用高峰倍率时，指定时间段还会额外乘以高峰倍率。

例如，模型基础费用为 `$1.00`，当前生效倍率为 `0.07`，则实际扣费约为 `$0.07`。示例仅用于说明计算方式，不代表当前线上倍率。

当前下方列出的分组均未启用高峰倍率。密钥页面显示的倍率和使用记录中的最终费用具有更高优先级。

### 图片与其他按次能力

图片生成、视频生成或网页搜索可能按图片规格、生成次数或调用次数计费，不一定使用 Token 计费方式。最终扣费仍以使用记录为准。

### 余额与使用记录

- 请求成功后，费用会从账户余额中扣除。
- 失败请求是否产生费用取决于上游是否已经产生有效用量。
- 使用记录可按密钥、模型和时间筛选，适合核对单次请求与余额变化。
- 建议为不同设备或用途创建独立密钥，便于统计和停用。

## 分组说明

倍率表示相对于模型基础费用的计费比例，不代表模型性能或请求成功率。分组名称、平台、倍率和模型权限以当前页面显示为准。

### 如何查看当前分组

1. 打开[密钥管理](/keys)，创建或编辑 API 密钥。
2. 查看密钥可用的分组、平台、倍率和模型权限。
3. 需要比较模型价格时，打开模型广场，确认模型的输入、输出、缓存价格以及分组倍率。
4. 选择分组后保存密钥，再用目标客户端发送一次最小请求验证。

### 如何选择分组

- 使用 Codex 时选择当前可用的 OpenAI 平台分组，并确认模型列表包含目标 Codex 模型。
- 使用 Claude 或其他平台时，选择对应平台且明确支持目标模型的分组。
- 临时福利或测试分组可能随上游容量变化，不适合作为唯一备用方案。
- 对稳定性有要求时，可以为不同分组分别创建密钥，客户端异常时直接切换密钥。

### 如何切换分组

进入[密钥管理](/keys)，编辑已有密钥并选择新分组，或为目标分组创建新密钥。分组修改只影响后续请求，不会改变历史使用记录。

## 常见问题

### 为什么实际费用和简单估算不同

输入、输出、缓存、长上下文和服务层级可能使用不同单价；账户专属倍率也可能覆盖表中的默认倍率。请以使用记录中的最终费用为准。

### 为什么看不到某个分组

分组可能已暂停、调整权限、变更为订阅专属或暂时下线。刷新密钥管理页面后仍不可见时，请选择当前可用分组，不要继续使用旧教程中的分组名称。

### 返回 401 或 403

401 通常表示 API 密钥无效、已删除或复制错误。403 通常表示密钥未绑定有效分组，或当前分组没有对应模型权限。

### 返回 429

429 通常表示请求频率、并发或上游容量达到限制。等待正在运行的请求结束后重试，也可以切换到其他可用分组。

### 模型不可用

确认请求模型属于当前分组支持的平台。不要仅根据其他教程中的模型名称填写；应以密钥管理页面和实际模型列表为准。
