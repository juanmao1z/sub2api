# 会话与配置恢复

本页说明如何使用 `codex++` 恢复 Codex 会话记录和本地配置。

会话记录不会保存在服务器，而是保存在你运行 Codex 的本地设备上。切换设备、重装系统或清理本地目录后，服务器无法替你找回本地会话。

## 如何恢复记录

推荐使用 `codex++` 管理和恢复 Codex 会话记录。

1. 打开 `codex++`，进入会话管理功能。
2. 执行“会话同步”“Provider 同步”或“历史会话修复”（不同版本的按钮名称可能略有差异）。
3. 等待同步完成后，完全退出 Codex 及 `codex++`。
4. 从 `codex++` 重新启动 Codex，检查历史会话是否恢复。

## 恢复前注意事项

- 不要删除本地 `.codex` 目录或其中的数据库文件。常见位置包括 `~/.codex/sqlite/*.db`，旧版本也可能使用 `~/.codex/state_5.sqlite`。
- Windows 用户可在用户目录下查找 `.codex` 文件夹；macOS/Linux 用户可在主目录下查找 `.codex` 文件夹。
- 需要换电脑或重装系统时，请先备份 `.codex` 目录，再在新设备上恢复到对应的用户目录。
- 如果同步后仍看不到记录，请确认使用的是原来的本地用户目录，并检查 `codex++` 当前选择的供应商配置。

## 配置恢复

恢复配置时，请从原设备备份 `.codex` 目录中的配置文件，再复制到新设备对应的用户目录。完成复制后，关闭并重新打开 `codex++`，再启动 Codex 检查供应商、模型和会话是否正常。
